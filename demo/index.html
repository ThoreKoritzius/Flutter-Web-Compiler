EXPERIMENTAL, WITH A CLEAR CONTRACT

Document-first today. Broader compatibility next.

Current strengths: static content, constructor data, native search and deferred Flutter. Current gaps: multi-file type resolution, reactive state, async data, routing, package integration and exact layout fidelity. A native adapter implements a known behavior; it does not translate arbitrary Dart callbacks.
